    Notifications

    New rules start observing without an immediate alert. Alerts rearm after recovery; seasonal alerts require several weeks of comparable hourly history.

    Global defaults apply to all games unless overridden individually in the Games section.

    Global Switch
    Enable notifications
    Master switch. When off, no alerts are sent for any game.
    Default Thresholds
    Rise alert
    Notify after the 7-day seasonal trend crosses this percentage for 5 minutes.
    +30%
    Drop alert
    Notify after the 7-day seasonal trend crosses below this percentage for 5 minutes.

    About

    SteamWatch
    Track Steam games with live player data, local history, and alerts.
    Version  ·  GitHub repository
    Independent project SteamWatch is an independent open-source extension. It is not affiliated with Valve or Steam. All tracked data is stored locally in your browser.

    Data Sources

    SteamWatch uses public data sources for player counts, peaks, search, artwork, and Twitch viewer information.

    Steam Web API - current players SteamCharts - 24h peak and bootstrap history SteamSpy - all-time peak Steam Store Search - autocomplete Steam CDN - game artwork Twitch - live viewers
